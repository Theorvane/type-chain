# Governance

The Theorvane maintainers steward TypeChain’s roadmap, security response, release process, and public API compatibility. Small changes use the issue/PR process; public API, tool safety, license, and governance changes require explicit maintainer approval and rationale.

Only authorized maintainers may promote `dev` to release-only `main` or publish to npm. Material policy or API decisions should be recorded in issues, PRs, or architecture decision records.
